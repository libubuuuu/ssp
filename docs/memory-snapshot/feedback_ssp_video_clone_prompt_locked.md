视频复刻「✨ 一键生成提示词」的输出格式已锁定（2026-06-07 用户确认），**任何情况下不得改动**。

**锁定格式（2026-06-12 用户授权更新人物句，commit 3dfa05c）：**
```
以 @视频1 为参考视频,保持其运动、构图和节奏。{产品替换句}。新视频中保留原视频里的台词和声音、字幕和旁白。生成的人物要和说话内容对准口型。[上传的@人物1 脸上的涂鸦去掉，脸部颜色要和身体的皮肤颜色对得上，换成真实的人物形象，头要小于身体。]（有人物图才加）
```

**关键规则：**
- 同类型多张图合并一句，用顿号隔开：`把视频里人物的下装换成@产品1、@产品2`
- 不经过 AI 改写（DeepSeek/compact），直接本地拼接输出
- 用户选了"不保留台词"才去掉台词那句，否则保留
- 人物图才加涂鸦那句，产品/场景图不加

**Why:** 用户多次因 AI 改写导致输出乱掉（重复句子、格式跑题）非常生气，明确要求锁定不变。

**How to apply:** 改这个函数前必须先问用户，得到明确同意才能动。
