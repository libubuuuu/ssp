## 改了什么

### 1. 修订 `docs/legal/terms-of-service.md`

| 章节 | 改动类型 | 说明 |
|---|---|---|
| §4.2 内容审核 | **改写** | 把"我们对您输入的提示词与生成的内容实施自动化内容安全审核"改为分级表述:基础黑名单过滤 + 第三方 safety checker;**视频复刻 V2 等高自由度业务仅依赖第三方 safety checker,不进行平台自有预审**;扣费 / 退费规则改为按各业务模块在生成入口处的明确说明执行(为 V2 fal-rejection 全额退留路) |
| §4.3 您的责任 | 不动 | 已经够强 |
| §4.4 视频复刻 / 深度合成专项责任 | **新增 5 个子节** | 4.4.1 上传内容合法权属 / 4.4.2 严格禁止的输入与生成(列 8 类)/ 4.4.3 商业使用的额外要求 / 4.4.4 您理解并接受(平台不审核 + 全额追偿 + 配合执法)/ 4.4.5 上传声明书引用 |
| §6.3 V2 标识与双版本下载 | **新增 + v2 重写** | v1 强制可见水印不可移除 → **v2 改为双版本输出(合规版 + 无标识版),用户主动选择**;合规版水印参数对齐用户最终决议(字号 3%,不透明度 30%,Noto Sans CJK SC,文字"AI 生成");无标识版仍含隐式 metadata 不可移除;§17 法定义务在用户选无标识版时转移给用户 |
| §4.4.6 无标识版下载专项承诺 | **v2 新增** | 用户选无标识版即承诺:放弃平台标识 / 自行加合规标识 / 全额承担因未标识公开传播的所有责任;留痕作为事后证据;独立追加于 §4.4.4 |

**未动**:§5 知识产权、§7 付费退款、§8 第三方服务、§9 服务变更与终止、§10 免责声明、§11 联系我们、§12 适用法律。

### 2. 新建 `docs/legal/video-clone-v2-upload-disclaimer.md`

**用途**:V2 上传弹窗专用声明书。前端"开始生成"按钮前必弹,用户必勾全部框才能继续。

**结构**(短而强,目标用户能 1 分钟读完):
- 为什么需要这份声明(法规依据 + 平台不审核背景)
- 「我承诺」 **C1-C7 共 7 项**(视频权属 / 人物同意 / 产品权属 / 8 类禁止 / 商业合规 / 不移除水印含隐式标识 / **C7 新增:双版本下载知悉**)
- 「我知悉并接受」 A1-A5 共 5 项(平台不预审 / 第一责任人 / 全额追偿 / 配合执法 / 单次声明)
- 最终确认 ☐ 1 个总勾(C1-C7 + A1-A5)

## 这份草案的边界(我没替用户做的事)

1. **占位符未替换**:`{{COMPANY_NAME}}` `{{COMPANY_SHORT}}` `{{PRODUCT_DOMAIN}}` `{{ICP_NUMBER}}` `{{CONTACT_EMAIL}}` 等遵循项目既有占位符约定(详见 `docs/legal/README.md`),由用户在上线时替换。
2. **法务/律师审阅**:本草案仅为 Claude 起草,**正式上线前必须由用户委托法务或律师审阅**。我不是律师,本草案不构成法律意见。
3. **frontend mirror 同步**:`/root/ssp/frontend/src/legal/terms-of-service.md` 与 `docs/` 主版本之前完全一致(diff 已比对)。本次修订**只动 docs/ 主版本**,frontend mirror 等用户审完后我同步,以及前端 `/terms` 页面渲染调整放在 P221 阶段 C(前端 UI 阶段)一起做。
4. **新页面渲染**:`docs/legal/video-clone-v2-upload-disclaimer.md` 还没有对应的前端渲染页(待阶段 C)。本次只产 markdown 内容。
5. **上传弹窗 UX**:弹窗如何渲染、何时弹出、勾选状态如何上报后端、后端如何记录"用户已确认"(疑似需新增 `video_clone_v2_disclaimer_log` 表 — 以便事后举证用户确认行为)是阶段 A 后期 / 阶段 C 的事,本次先不做。**但举证表确实重要**(对应 §4.4.4 "无须事先通知地披露"的事后审计需求),建议本周阶段 A1 时一起把表建了,弹窗 UX 留 C 阶段。
